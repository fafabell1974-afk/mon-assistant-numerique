Où sont stockées vos données ?
Toutes les données (clients, appareils, interventions) sont stockées localement dans votre navigateur via IndexedDB. Aucune donnée n'est envoyée sur nos serveurs.

Clés API
Votre clé API IA reste dans le stockage local de votre appareil. Elle n'est jamais incluse dans les sauvegardes.

Google Drive
Les sauvegardes sur Google Drive utilisent votre compte Google. Seules les données de l'application sont transférées (jamais les clés API).

Assistant IA
Seul le contexte technique que vous choisissez d'envoyer est transmis au fournisseur IA. Aucune donnée personnelle client n'est envoyée automatiquement.

Recommandation
Utilisez le verrouillage par PIN et verrouillez votre appareil mobile pour protéger les données de vos clients.
